## 来源与脱敏说明

- 课程：企业战略管理；文档：第 3 章“科大讯飞”上市十年的变与不变。
- 以下参数来自上一轮已保存的真实脱敏样例 `ac_mark_samples.json`，并按其中的完整参数重组成可重放的等价 cURL。
- 这是参数级证据，不冒充本轮 Firefox DevTools 的直接“Copy as cURL”；本机 Firefox DevTools 当前报 `No such JSProcessActor 'DevToolsProcess'`。
- Cookie、uid、markDataStr 中的 token 均已脱敏（uid → `<uid>`）；不要将真实 Cookie 或 token 写入仓库。

## 对比结论

- 两条请求的 `d` 仅 `s` 从 `1` 变为 `2`，`t` 是 17 位毫秒时间戳，`enc` 随之变化。
- 对参数名排序后，使用 `encodeURIComponent(d)` 的值与 `f/u/t` 拼接，再追加前端盐 `NrRzLDpWB2JkeodIVAn4`，其 MD5 分别得到上面的两条 `enc`。
