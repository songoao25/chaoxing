  courseId=<courseId>, classId=<clazzId>,

  uuid=<前端随机 UUID>,              // 网页端 RichTextUitl.randomUUID() 生成
  topic_content=<encodeURIComponent(正文)>,
  files_url=, files_attr=, anonymous=,
  urlToken=<页面里的 urlToken>, bbsid=<bbsid>
响应：{status:true, msg:回复成功, datas:{reply:{...}, urlToken:<新 token>}}
      status=true 且没有 datas = 回复待审核（也算提交成功，最终完成仍看任务引擎）

## 5. 完成判定

任务中心 getPlanDataByGroupId 的 isFinish / planUser.finish（和其他类型一样），
接口返回成功只代表“回复被接受”，不代表任务点完成。
实测同步有延迟：22:28 复查 isFinish=false → 22:31 复查 isFinish=true（约 3 分钟），
不需要额外的同步接口，等待+复查即可。

## 6. 关键结论

1. 讨论区域名是 groupweb.chaoxing.com，和章节/作业/任务引擎都不是一套接口。
2. getToStudyUrl 对 planType=14 会返回 bbsId + topicUuid + 详情页 URL（此前探针截断
   URL 看起来像“取不到”）。
3. 回复正文统一走 api/ai_writer.py 的 HumanLikeWriter.discussion（模仿已有回复、去 AI 味）；
   生成器判定“编造个人经历/平台话术”等硬伤时直接放弃提交（实测模型会写“我在奶茶店做过兼职”）。
4. urlToken 每次提交后会换新，所以每次回复都要重新打开话题页取 token。
