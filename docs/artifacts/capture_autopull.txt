## 5. 踩坑记录：Python requests 打点 403，curl / 浏览器 200

2026-09-17 实测：同一时刻、同一个 URL、同一套查询参数与 Cookie、同一个 User-Agent：

| 客户端 | HTTP | 响应 |
| --- | --- | --- |
| Google Chrome（headless，真实播放） | 200 | `{"isPassed":...}` |
| Python `requests`（urllib3 / OpenSSL） | **403** | `【9011】很抱歉，您没有权限访问这个页面！code=6` |
| 系统 `curl`（SecureTransport / LibreSSL，HTTP/1.1） | 200 | `{"isPassed":...}` |

结论：这是**客户端指纹级拦截**（TLS/HTTP 客户端特征），不是账号风控、不是参数错误，也不是 HTTP/2 的问题。
CLI 侧的处理：`api/base.py` 的 `video_progress_log` 在 requests 返回 403 时，用 `_curl_get()`
以完全相同的参数与 Cookie 走一次 curl（cookie 通过 stdin 传给 curl，不出现在命令行），
重放成功则继续按正常响应处理；curl 也失败才走原来的验证码/403 分支。
